# Выбранная архитектура

## Облачное хранилище (Яндекс Диск)
Система позволяет загружать, хранить и работать с пользовательскими данными с возможностью совместного доступа к ним

Пользователи/акторы, которые работают с системой:
1. Пользователь, который загружает или работает с данными и управляет доступом к ним через выделенный интерфейс

## Ключевые сценарии
1. Загрузка, создание, редактирование файлов
2. Поиск и просмотр файлов
3. Скачивание файлов
4. Совместная работа и выдача прав доступа
5. Управление оплатой за услуги, управление тарифами - биллинг
6. Синхронизация данных с устройств (синхронная автозагрузка в реальном режиме времени или асинхронная)
7. Проверка антивирусом

## Масштаб работы
Миллионы пользователей - 20-25млн
Объем пользовательских данных - более 100 Петабайт
RPS - 100-200 тысяч RPS

# 1. Компоненты

1 Интерфейс -> 2 CDN -> 3 Балансировщик -> 4 API Gateway -> 5 Сервисы (микросервисы) -> 6 БД


## 1.Клиентские интерфейсы: 
Веб-версия, мобильное приложение, десктопное приложение, REST API, приложение для ТВ
За что отвечает: Предоставление возможности пользователю работать с сервисами облачного хранилища

## 2.CDN 
За что отвечает: доставка контента/данных с ближайших к пользователю серверов, используется для распределенных систем с большой нагрузкой

## 3. Балансировщик (Load Balancer)
За что отвечает: балансирует нагрузку, распределение трафика между серверами


## 4.API Gateway
За что отвечает: аутентификация, управление потоками данных и маршрутизация запросов между сервисами, агрегация ответов от сервисов

## 5.Сервисы (микросервисы)

## 5.1 Сервисы работы с файлами (просмотр, загрузка, создание, скачивание, редактирование, удаление)
За что отвечает: работа с файлами в облачном хранилище

## 5.2 Сервис поиска
За что отвечает: быстрый поиск данных в хранилище

## 5.3 Сервис управления доступом
За что отвечает: управление правами доступом к файлам

## 5.4 Сервис безопасности проверки данных (антивирус)
За что отвечает: проверка безопасности загружаемых файлов

## 5.5 Сервис оплаты (биллинг услуг)
За что отвечает: проведение оплаты и подписки на пользование услугами хранения данных


## 6. База данных - Хранилище метаданных
За что отвечает: Структурированное хранилище данных для получения ссылок на файлы из объектного хранилища

## 7.База данных - Объектное хранилище данных
За что отвечает: Хранение больших файлов - байты файлов (картинки, видео, документы)
